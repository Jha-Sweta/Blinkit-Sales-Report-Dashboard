# 🛒 Blinkit-Sales-Report-Dashboard

A visually interactive Power BI dashboard project analyzing **Blinkit’s sales data**, customer behavior, and outlet performance across various categories. This report helps uncover insights into product trends, outlet types, and consumer ratings.

---

![Dashboard Preview](https://github.com/user-attachments/assets/a6797282-dc4b-4960-83e4-14d086ca295a)

---

## 📊 Key Metrics & Highlights

- 💰 **Total Sales:** ₹1.20M+
- 📦 **Number of Items:** 8,523
- ⭐ **Average Ratings:** 3.9
- 📈 **Average Sales per Item:** ₹141

---

## 🎯 Features

- **Dynamic Filtering Panel** (by Outlet Type, Size, and Item Type)
- **Fat Content Analysis** (Low Fat vs. Regular)
- **Outlet Establishment Trend** (Year-wise visualization)
- **Outlet Size & Tier-Wise Sales Breakdown**
- **Item Type vs. Rating Comparison**
- **Outlet Type KPIs Table** with visibility, ratings, and item counts

---

## 📂 Project Files

- `Blinkit Sales Report.pbix` – Power BI dashboard file

## 🛠️ Built With

- **Microsoft Power BI**
- **Power Query** – for ETL and data cleansing
- **DAX** – to create custom measures and calculated fields

---

## 🧠 Business Insights

- Supermarket Type1 dominates with over ₹787K in sales
- Tier 3 locations outperform Tier 1 and Tier 2 in revenue
- Medium-sized outlets are the highest earning by size
- Average customer rating across categories is consistent (~4.0)

---

## 📝 How to View

1. Download the `.pbix` file
2. Open it using **Power BI Desktop**
3. Interact using filters for outlet type, size, item category, and more
